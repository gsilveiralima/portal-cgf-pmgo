# Portal CGF PMGO

Portal público de orientação do Comando de Gestão e Finanças da Polícia Militar do Estado de Goiás.

## Finalidade

- orientar o público sobre as atribuições de cada seção;
- indicar contatos e caixas SEI institucionais;
- facilitar o acesso aos canais oficiais;
- exibir atualizações públicas da PMGO.

O portal não recebe protocolos, não armazena dados do visitante e não contém procedimentos internos de lançamento em folha.

## Publicação

Conteúdo estático preparado para GitHub Pages. As informações devem ser confirmadas nos canais oficiais da PMGO.
